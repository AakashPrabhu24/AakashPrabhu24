## 💡 Engineering Principles I Build By

* **1. Determinism Around Probabilism:** Generative models are creative; production systems require reliability. Always wrap LLM prompts in strict JSON schemas, regex constraints, and deterministic fallbacks.
* **2. Edge Over Network:** If an information retrieval or TF-IDF calculation can be executed in under 15ms in the user's browser, never force a roundtrip to a cloud server.
* **3. Event-Driven Concurrency:** Use WebSockets and asynchronous workers over repetitive polling. Milliseconds matter when coordinating critical emergency alerts or matching real-time queries.
* **4. Measurable Rigor:** Code without benchmarks is conjecture. Profile latency, token usage, and database indices obsessively.
